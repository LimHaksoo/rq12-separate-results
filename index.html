1. 데이터 규모와 판정 성공률

  • pair 이미지 2,000장(100쌍 x 순서 2 x seed 10)을 판정했습니다.
  • 판정 성공 1,963장, VLM 오류 37장입니다.
  • segment 결과는 ok 1,745, ambiguous_regions 58, missing_detection 197입니다. 영역 실패는 255장(12.8%)입니다.
  • 누수 판정 대상은 1,260장입니다. 나머지 703장은 병합, 영역 실패, 불확실 등으로 자격 조건에서 빠졌습니다.

2. 라벨 분포 (RQ0)

누락은 B에서 더 많습니다. A가 6.6%, B가 12.8% 빠집니다. 두 순서를 합친 값이라 프롬프트 어순 효과가 아닙니다. A는 개체 목록에서 앞에 오는 개체이고, 이 개체들이 더 자주 살아남는다는 뜻입니다. 개체마다 세기가 다르다는 가설과 방향이 맞습니다.

병합은 20.3%입니다. 분리 문구를 넣었는데도 다섯 장 중 한 장은 섞입니다. 변동이 충분해서 통계적으로 다루기 좋은 결과 변수입니다.

누수 라벨은 1~2%뿐입니다. 시각적 인상과 차이가 크므로, 현재 값은 현상 자체보다 측정 방식의 문제를 먼저 의심해야 합니다.

5. 누수를 놓치는 구조

  • 속성 고정: 개체당 2~3개만 봅니다. 목록에 없는 색 번짐이나 질감 전이는 세지 않습니다.
  • 공유 속성 제거: 같은 문자열 속성을 빼기 때문에, 겹침이 큰 pair일수록 볼 속성이 줄어듭니다.
  • 자격 조건: 둘 다 존재하고, 병합이 아니고, 영역이 유효하고, 영역이 이름과 맞아야 합니다. 이 조건에서 703장이 빠집니다.
  • 프롬프트: "나열된 속성만 보라"고 지시하고 있어 모델이 보수적으로 답합니다.

6. 다음 작업

  • 개방형 판정 경로 추가: 속성 목록 없이 "B에 A의 특징이 나타났는가, 있다면 무엇인가"를 자유 서술로 받습니다. 기존 목록 기반 판정도 남겨 둡니다.
  • 자격 조건 완화: 영역이 없거나 병합으로 빠진 이미지도 전체 이미지만으로 개방형 판정을 돌립니다. 병합 이미지는 "병합이면서 누수"로 따로 기록합니다.
  • HAK 라벨 100장: 검수 HTML에서 누수 있음/없음과 방향을 표시합니다. 이 100장으로 두 판정 방식의 재현율과 정밀도를 계산합니다.
  • 점검: 임계값 적용, malformed_a=0, 내부 누수 지표 비대칭, bootstrap CI를 확인합니다.

진행 상태: review100 샘플 100장에 대해 개방형 Qwen 판정을 별도 실행했습니다. 결과는 ok 100/100, open_leak_a_to_b 23/100, open_leak_b_to_a 12/100, merged_with_transfer 17/100입니다. 이 값은 HAK 라벨과 비교하기 전의 자동 판정 수치입니다.

7. 정리

압도와 병합은 지금 데이터로도 가설과 맞는 신호가 보입니다. 누수는 판정을 고쳐야 판단할 수 있습니다. RQ1의 rho는 정의나 NaN 처리를 손봐야 할 가능성이 있습니다. 가장 먼저 할 일은 100장 사람 라벨과 개방형 판정 비교입니다.
